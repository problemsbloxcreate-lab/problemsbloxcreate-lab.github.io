Instalar a CelestIA

A CelestIA é a ajudante do Estúdio Problems que roda no Claude Code do seu computador. Com ela, toda mudança começa pelo Cérebro (a memória da equipe) e tudo o que a IA aprende volta para ele.

Para a pessoa

  1. Abra o Claude Code no seu computador.
  2. Cole o texto abaixo e siga o que ele pedir.
  3. Quando ele mostrar um código que começa com c-, abra o Cérebro › Acesso das IAs, logada na sua conta, cole o código e clique em Autorizar. Não precisa de ADM.
Instale a CelestIA do Estúdio Problems neste computador e ligue o Cérebro.
1. Baixe o programa do Cérebro (não tem chave nenhuma dentro): https://problemsbloxcreate-lab.github.io/cerebro/cerebro.mjs
   PowerShell: Invoke-WebRequest https://problemsbloxcreate-lab.github.io/cerebro/cerebro.mjs -OutFile cerebro.mjs
   Mac/Linux: curl -fsSL https://problemsbloxcreate-lab.github.io/cerebro/cerebro.mjs -o cerebro.mjs
2. Rode: node cerebro.mjs instalar. Ele cria a chave só neste computador e mostra um código c-...
3. Me mostre o código e espere eu colar em https://estudio.problemsraiz.workers.dev/cerebro/?aba=chaves (logado na minha conta).
4. Rode de novo: node ~/.claude/cerebro.mjs instalar (baixa as skills e liga o aviso do começo das conversas).
Depois disso, em toda tarefa do Estúdio: antes de mudar qualquer coisa, rode node ~/.claude/cerebro.mjs conferir (e instalar, se ele pedir) e leia no Cérebro a página do programa; depois, grave no Cérebro o que mudou ou o que aprendeu.

Para a IA que está instalando

Pergunte antes de começar (uma vez, curto):

  • Este computador é seu e o Claude Code está instalado nele?
  • Que nome dar a este computador? (ex.: "notebook de casa")
  • Você já tem conta no Estúdio Problems e entra pelo menu com o Google?

Depois:

  1. Baixe o cerebro.mjs (link acima) e rode node cerebro.mjs instalar. Ele copia o programa para ~/.claude, cria a chave só neste computador e mostra um código c-…. O código não é segredo; a chave nunca sai daqui.
  2. Mostre o código e o link do Acesso das IAs. Espere a pessoa dizer que autorizou.
  3. Rode node ~/.claude/cerebro.mjs instalar de novo: ele baixa as skills (CelestIA, design, animação, ouvir…) e liga o aviso do começo das conversas no settings.json, sem apagar o que já existe.
  4. Rode node ~/.claude/cerebro.mjs comece e siga o que o Cérebro manda.

Regra de toda tarefa do Estúdio: antes de mudar algo, conferir (e instalar se ele pedir) e leia a página do programa no Cérebro. Depois, grave o que mudou ou aprendeu (salvar ou aprender, com quem pediu e qual IA gravou). Nunca grave senha, chave, token nem e-mail.

Usa o Claude no navegador (claude.ai)?

O claude.ai não roda comandos. Peça a alguém da equipe as pastas das skills em .zip, suba em Configurações › Skills e cole nas Preferências: "Antes de qualquer tarefa do Estúdio Problems, leia o Cérebro (https://estudio.problemsraiz.workers.dev/cerebro/), comece pela skill celestia e cite o Cérebro numa linha no fim de cada resposta." O que for aprendido lá, grave depois pelo Claude Code.
